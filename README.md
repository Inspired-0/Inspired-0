## Избранные проекты

### SocialBot

**Проблема:** повторяющиеся действия в социальных сетях требуют автоматизации, но полностью автономный агент создаёт риски ошибочной отправки, спама и компрометации аккаунта.

**Решение:** браузерный агент с детерминированным исполнительным контуром, подтверждениями опасных действий, квотами и редактированным журналом событий.

`Python` · `Playwright` · `LLM tool calling` · `Policy engine` · `Automated tests`

[Case study](case-studies/socialbot.md) · **Closed source**

### DemoAnalysis

**Проблема:** ручной разбор записей встреч не масштабируется, а свободный ответ LLM может содержать неподтверждённые выводы и цитаты.

**Решение:** идемпотентный pipeline со структурированным LLM-анализом, проверкой цитат, устойчивым состоянием и контролируемой доставкой результатов.

`Python` · `SQLite` · `Pydantic` · `LLM API` · `pytest`

[Case study](case-studies/demo-analysis.md) · **Closed source**
