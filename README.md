### SocialBot

Помогает выполнять повторяющиеся действия в социальных сетях. Агент может прочитать новые сообщения и подготовить ответ. Перед отправкой он просит подтверждение пользователя.

### DemoAnalysis

Собирает записи встреч, анализирует их и сохраняет результат в рабочую таблицу. Система проверяет ответ модели и ищет каждую цитату в исходном тексте встречи.

`Python` · `SQLite` · `Pydantic` · `LLM API` · `pytest`

[Подробнее о проекте](case-studies/demo-analysis.md) · **Код закрыт**

### SkinCheck AI

Показывает безопасную работу с изображениями кожи. API проверяет файл, передаёт его провайдеру и проверяет ответ по схеме. По умолчанию работает тестовый провайдер без ключа и внешних запросов.

`TypeScript` · `React` · `Vite` · `Express` · `Zod`

[Открыть код](https://github.com/Inspired-0/skincheck-ai) · **Открытый код**

### Telegram Claude Agent

Связывает личный Telegram чат с Claude CLI. Бот принимает сообщения только от владельца, разрешает безопасный набор инструментов, скрывает чувствительные данные в журналах и хранит сессии без текста переписки.

`Python` · `aiogram` · `Claude CLI` · `pytest`

[Открыть код](https://github.com/Inspired-0/telegram-claude-agent) · **Открытый код**

### AI Legal Docs

Извлекает данные из запроса, проверяет их и заполняет DOCX по шаблону. Модель не пишет юридический текст. Она только возвращает значения для заранее описанных полей. Демо работает без ключей и использует вымышленные данные.

`Python` · `DOCX` · `docxtpl` · `pytest`

[Открыть код](https://github.com/Inspired-0/ai-legal-docs) · **Открытый код**
